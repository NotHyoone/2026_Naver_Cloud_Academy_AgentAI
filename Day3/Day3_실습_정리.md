## 3. Lab 00 — 실습 전용 폴더 만들기 (필수 · 5분)

**왜 전용 폴더인가?** 문서·다운로드·바탕화면을 연결하면 내 파일 전체를 새 동료에게 보여 주는 것과 같다. 폴더는 Cowork가 **읽기·쓰기 권한을 모두** 갖는 곳이므로, 작업에 필요한 파일만 복사해 넣은 **가장 작은 폴더**를 고른다. 대체 불가능한 원본은 시작 전에 따로 백업한다.

1. 폴더 만들기 — Windows: `문서(Documents)\Claude-실습` / macOS: `문서(Documents)/Claude-실습`
2. 하위 폴더 2개: `입력`(원본 복사본을 넣는 곳), `결과`(Claude가 만든 새 파일이 저장될 곳)
3. `입력`에 샘플 파일 넣기(강사 제공 또는 메모장으로 직접 작성)

```text
Claude-실습
 ├─ 입력
 │   ├─ 지출내역.csv
 │   └─ 강의메모.txt
 └─ 결과   (비어 있음)
```

`지출내역.csv` 예시:

```csv
날짜,항목,분류,금액
2026-11-02,학식,식비,5500
2026-11-03,교재,학습,18000
2026-11-04,버스,교통,1500
2026-11-05,카페,식비,4800
2026-11-06,USB 메모리,학습,12000
```

## 5. Lab 02 — Cowork에 폴더 연결하고 첫 작업 맡기기 (필수 · 25분)

흐름: **위임 → 확인 질문 → 방향 조정 → 결과 검토**

### 2-1. 폴더 연결

1. Cowork 탭 → 새 작업
2. 프롬프트 바에서 **[프로젝트 또는 폴더에서 작업하기]** 클릭
3. `Claude-실습` 폴더만 선택(문서 전체·다운로드·바탕화면 선택 금지)
4. 권한 모드: **"작업 전 확인"(기본값) 그대로 유지** → 기록 카드 5)
5. 커넥터(Gmail · Drive 등)는 오늘 **모두 꺼 둔 상태**로 진행
6. 확인: 프롬프트 바에 `Claude-실습` 폴더가 표시됨. Claude는 연결한 폴더 안만 읽고 쓸 수 있다.

### 2-2. 몸풀기 — 폴더 브리핑 받기

```text
이 폴더에 있는 모든 것을 살펴보고, 알게 된 내용에 대한 브리핑을 작성해줘
— 폴더에 무엇이 있는지, 문서들이 서로 어떻게 연관되어 있는지,
놀라운 발견이 있는지, 또는 공유할 만하다고 생각되는 다른 정보가 있는지.
```

브리핑을 내가 아는 내용과 비교한다. Claude가 내가 놓친 무엇을 포착했나? 무엇을 놓치거나 잘못 이해했나?

### 2-3. 좋은 Cowork 프롬프트 = 결과물 + 입력 + 뉘앙스

처음에 한 번 제대로 말하면 "아, 그리고 이것도…"를 다섯 번 반복할 필요가 없다.

```text
[결과물] 결과 폴더에 "이번주-지출-정리.md"라는 한 페이지 요약을 새 파일로 만들어줘.
[입력]   입력 폴더의 지출내역.csv와 강의메모.txt만 참고해.
[뉘앙스] 분류별 합계 표를 먼저 보여주고, 다음 주 절약 팁 3가지를 붙여줘.
         원본 파일은 절대 수정하지 마. 확인할 수 없는 내용은 "확인 필요"로 표시해.
```

### 2-4. 확인 질문 답하기 · 작업 중 방향 조정

1. **확인 질문에 답하기**: 착수 전 한두 개의 질문은 맥락의 공백을 메우는 과정이다. 선택지가 맞으면 클릭, 없으면 내 말로 답한다. 건너뛰면 Claude가 추측해야 한다.
2. **계획(진행 상황) 읽기**: 진행 상황 패널에 표시된 순서·사용 파일이 맞는지 훑어본다.
3. **작업 중 방향 조정**: 잘못된 방향이면 끝날 때까지 기다리지 말고 바로 메시지를 보낸다. Cowork는 중단된 지점부터 이어서 진행한다.

   ```text
   표는 분류별이 아니라 날짜순으로 바꿔줘. 나머지는 그대로 진행해.
   ```

### 2-5. 완성된 결과물 검토

1. 앱에서 결과 파일을 미리 보기로 확인
2. 탐색기(Finder)에서 `Claude-실습/결과`에 파일이 실제로 생겼는지 확인
3. `입력` 폴더 원본이 바뀌지 않았는지 확인
4. 동료의 초안을 읽듯이 검토

| 점검 | 질문 |
| --- | --- |
| 목표 | 내가 요청한 것과 미묘하게 다른 것을 만들지 않았나? |
| 사실 | 합계·숫자가 원본 CSV와 일치하나? |
| 지어냄 | 원본에 없는 날짜·이름·인용이 있나? |

대체로 맞으면 바꿀 점만 알려 주고(재생성보다 빠름), 핵심이 틀렸으면 빠진 맥락을 추가해 다시 요청한다.
결과: `결과/이번주-지출-정리.md` 생성 · 원본 그대로 → 기록 카드 6)

## 6. Lab 03 — 승인 요청 화면 읽는 법 (필수 · 10분)

### 3-1. 권한 모드와 안전장치

| 모드 | 동작 | 오늘 |
| --- | --- | --- |
| 작업 전 확인(기본값) | 이메일 보내기·메시지 게시·파일 공유 등 외부에 영향을 주는 작업 전에 멈추고 승인을 기다림 | **사용** |
| 확인 없이 작업(주의) | 승인을 위해 멈추지 않음. 신뢰하는 파일·사이트 + 내가 지켜볼 때만 | **금지** |
| 삭제 안전장치(항상) | 두 모드 모두에서 파일 영구 삭제 전에는 항상 확인 요청. 예외 없음 | — |

이 밖에 커넥터·MCP(무엇에 접근하고 얼마나 자주 권한을 묻는지)와 웹 접근(관리자가 웹 검색·방문 사이트 제한 가능)도 제어할 수 있다.

### 3-2. 승인 vs 거절 판단

| 승인 요청 내용 | 판단 | 이유 |
| --- | --- | --- |
| `결과` 폴더에 새 파일 만들기 | 승인 | 요청한 범위, 원본 보존 |
| `입력` 폴더 원본 덮어쓰기·수정 | 거절 | "원본 수정 금지" 위반 |
| 파일 영구 삭제 | 거절(오늘) | 되돌릴 수 없음 |
| 이메일·메시지 전송 / 게시 / 공유 | 거절(오늘) | 외부에 영향, 커넥터 꺼 둠 |
| 언급하지 않은 다른 폴더·사이트 접근 | 중단 | 범위 이탈 신호 |

> 대부분의 실수는 안전장치가 실패해서가 아니라 **의도와 정확히 일치하지 않는 확인을 그냥 클릭해서** 일어난다. 승인 버튼을 누르기 전에 대화상자 내용을 끝까지 읽는다.

### 3-3. 잘못된 작업의 여지를 없애는 프롬프트

| 모호한 요청 | 명확한 요청 |
| --- | --- |
| "섹션을 잘라내줘" | "초안에서 해당 섹션을 제거하되, 파일은 유지해줘" |
| "파일을 업데이트해줘" | "새 부록을 추가해줘. 기존 섹션은 다시 쓰지 마" |

- 범위 명시: "이 폴더에서 가장 최근 3개 파일만", "아무에게도 보내지 마 — 초안만 작성해줘"
- 그 순간의 3가지 점검: ① 계획을 한 번 읽기 ② 말하지 않은 파일·사이트를 건드리면 중단 ③ 확인 프롬프트를 신중하게 승인. "뭔가 이상하다"는 느낌은 실제 신호이니 멈추고 물어본다.

### 3-4. 퀴즈 — 이 작업, 무엇이 위험할까?

설정: 매주 금요일 오후 5시 예약 · 커넥터 Gmail·Google Drive·동아리 Slack·Claude in Chrome 켜짐 · 작업 폴더 `~/Documents`(문서 전체) · 권한 모드 확인 요청
프롬프트: "지난 학기 과제 파일 정리 — 오래된 자료 보관. 그리고 동아리 단톡방(Slack 채널)에 자료실이 정리되었다는 공지 게시."

| # | 위험 요소 | 더 안전하게 |
| --- | --- | --- |
| 1 | 폴더가 `~/Documents` 문서 전체(개인 파일까지 포함) | 이 작업 전용 폴더(복사본)만 연결 |
| 2 | "오래된 자료 보관" — 이동? 삭제? 모호 | "보관 폴더로 이동만, 삭제 금지" |
| 3 | 동아리 Slack에 공지 게시(외부 전송) | "게시하지 말고 초안만 작성" |
| 4 | 매주 금요일 자동 실행(지켜보지 않음) | 처음엔 사본으로 테스트, 초안 작성용으로만 |
| 5 | Gmail·Drive·Chrome 등 커넥터가 필요 이상으로 켜짐 | 이 작업에 필요한 커넥터만 켜기 |

예약 작업은 내가 지켜보지 않는 동안 실행된다. 원하는 대로 동작한다는 확신이 들기 전까지는 전송 대신 검토용 초안을 만들게 한다.

## 7. Lab 04 — 전역 지침과 프로젝트로 "나만의 규칙" 저장 (필수 · 10분)

매번 설명하지 않아도 Claude가 나의 업무 방식을 알고 시작하게 한다.

| 계층 | 범위 | 담는 내용 |
| --- | --- | --- |
| 전역 지침 — "나"에 대한 브리프 | 설정에서 한 번 작성 → 모든 세션(모든 채팅·예약 작업) | 내가 누구인지, 자주 쓰는 약어, 결과물 형식·길이·어조 |
| 프로젝트 — "작업 대상"에 대한 공간 | 이 프로젝트 안에서만 | 프로젝트 지침, 예약 작업, 참고 폴더·링크, 프로젝트 메모리 |

### 4-2. 전역 지침 작성·저장

1. 설정 → 전역 지침(버전에 따라 "Claude를 위한 지침")

## 9. Lab 06 — Claude 아티팩트로 6단계 웹 애플리케이션 만들기 (선택 · 15분)

핵심 키워드: **아티팩트(Artifacts) · 프롬프트(Prompt) · 게시(Publish) · 커스터마이즈(Remix)**

**아티팩트**는 대화창 우측에 독립적으로 열리는 실시간 작업 패널이다. 강점: ① HTML·CSS·JS를 브라우저에서 즉시 렌더링 ② 저장·빌드 없이 클릭 동작 검증 ③ 수정할 때마다 이전 버전(V1, V2)이 보존되어 언제든 복원.
Lab 05와 비교하면 **Cowork는 파일을 남기고, 아티팩트는 대화 옆에서 바로 실행**한다.

| 단계 | 내용 |
| --- | --- |
| 1. 접속 | `https://claude.ai` 또는 Claude Desktop의 Chat 탭. 오늘은 Lab 01의 팀 계정 사용(무료 플랜으로도 가능하다고 안내됨) |
| 2. 아티팩트 패널 열기 | 사이드바 [아티팩트(⊞)] → [+ 새 아티팩트] → [처음부터 시작하기]. 메뉴가 보이지 않으면 대화창에 바로 프롬프트를 입력하면 아티팩트가 자동으로 열림 |
| 3. 자연어 프롬프트 | 아래 대화 참고 |
| 4. 검증 | 우측 패널에서 렌더링 확인: 초 단위 디지털 시계, 시간대별 인사말, 한국어 날짜 형식, 검색창 호버·포커스 효과, 네이버·구글 검색 동작. [코드] 탭에서 HTML/CSS/Vanilla JS 단일 파일 구조 확인(`setInterval` 시계, 폼 제출 핸들러) |
| 5. 게시(Publish) | 우측 상단 [게시] → 안내 모달("링크가 있는 모든 사용자가 보고 리믹스할 수 있음") → [게시 및 링크 복사] → 새 탭에서 공개 URL 열고 검색 동작 확인 → 기록 카드 12) |
| 6. 커스터마이즈(Remix) | [사용자 지정] → [이 Artifact 커스터마이즈하기] → "구글 스타일로 디자인을 수정해 줘" → V1(미니멀)·V2(구글 스타일) 버전 비교. 메뉴가 없으면 같은 대화에서 이어서 요청 |

3단계 대화 흐름:

```text
나:     오늘의 날짜와 시간, 검색창이 있는 나만의 시작 홈페이지를 만들고 싶어.
Claude: (디자인 스타일 선택지 제시: 모던 미니멀 / 다크 모드 / 파스텔 톤)
나:     1번 모던하고 깔끔한 미니멀 스타일로 해 줘.
Claude: (검색 엔진 질문)
나:     네이버와 구글 검색을 모두 지원해 줘.
Claude: (날씨 위젯·북마크 추가 여부 질문)
나:     추가 기능은 나중에 넣을게. 지금 바로 웹페이지를 생성해 줘.
```

AI가 좋은 선택지를 제안하고 사용자는 고르기만 하면 된다. 핵심 기능(시계 + 검색창)을 먼저 완성하는 **MVP 후 점진적 확장**이 바이브 코딩의 정석이다.

게시 관련 주의:

- 아티팩트 게시는 **Anthropic이 호스팅**하고, Lab 05는 **내 NCP 서버가 호스팅**한다.
- Team · Enterprise 플랜은 관리자 설정에 따라 게시가 꺼져 있거나 공유 범위가 조직 내부로 제한될 수 있다. 링크 형식도 바뀔 수 있으니 화면에 표시된 링크를 사용한다.
- 공개 링크는 누구나 볼 수 있으므로 개인정보를 넣지 않고, 필요 없으면 게시를 취소한다.

### 7-2. 공용 PC 사용 시 반드시 — 연결 해제 체크리스트

1. Cowork 작업·프로젝트에서 `Claude-실습` 폴더 연결 해제
2. 실습 프로젝트 보관(필요 시 삭제)
3. 전역 지침에 개인정보가 없는지 확인, 공용 PC면 지우기
4. 공개할 필요 없는 아티팩트 게시 취소
5. 서버 접속 정리: VS Code Remote 연결 닫기 · MobaXterm 세션의 저장된 비밀번호 삭제 · Mac 터미널은 `exit`
6. 프로필 → [로그아웃]
7. 필요하면 `Claude-실습` 폴더를 USB·클라우드로 복사 후 PC에서 정리

> 로그아웃하지 않고 자리를 뜨면 다음 사람이 내 팀 계정 좌석으로 폴더·프로젝트·대화 기록에 접근하고, 저장된 세션으로 내 서버에 root로 접속할 수 있다.
> 개인 PC라면 폴더·프로젝트를 두고 다음 주에도 이어서 써도 되지만, 권한 모드는 "작업 전 확인"을 유지한다.

## 12. 달성 성과와 Day 4 예고
