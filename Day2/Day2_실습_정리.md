## 3. STEP 1 — 웹사이트 기획

### 1-1. 주제 고르기

| 주제 | 섹션 예시 |
| --- | --- |
| 자기소개 홈페이지 | 소개, 관심 분야, 프로젝트, 연락처 |
| 동아리/학과 소개 | 소개, 활동, 일정, 모집 안내 |
| 취미 소개 | 취미 설명, 사진 갤러리 자리, 추천 목록 |
| 미니 포트폴리오 | 기술 스택, 프로젝트 카드, 경력 타임라인 |

> 실제 전화번호, 주소 등 개인정보는 넣지 않는다.

### 1-2. 기획 메모(= 프롬프트 4요소)

```text
목표:   (예) 나를 소개하는 개인 홈페이지
내용:   (예) 이름, 학과, 관심 분야 3개, 프로젝트 3개
조건:   index.html 파일 하나에 CSS와 JavaScript 포함, UTF-8, 한글
스타일: (예) 파란색 계열, 카드형 디자인, 모바일 대응
```

## 4. STEP 2 — Claude로 첫 버전 만들기

### 2-1. 첫 프롬프트 입력

Claude 새 채팅에 입력한다(`[ ]` 부분을 내 기획으로 바꾼다).

```text
[영남대 ○○학과 ○학년 학생]의 [자기소개 홈페이지]를 만들어줘.
- 섹션: [소개, 관심 분야, 프로젝트(3개), 연락처]
- index.html 파일 하나에 CSS와 JavaScript를 모두 포함해줘
- 외부 이미지 파일은 사용하지 말고, 필요한 곳은 색상 박스나 이모지로 대신해줘
- <meta charset="UTF-8">을 넣어 한글이 깨지지 않게 해줘
- [파란색 계열의 깔끔한 카드형] 디자인, 모바일 화면에서도 보기 좋게
```

### 2-2. 결과 확인

- Claude 화면 오른쪽(또는 아래)에 미리 보기가 나타난다. 없으면 "HTML 미리 보기로 보여 줘"라고 요청한다.
- [ ] 요청한 섹션이 모두 있는가?
- [ ] 한글이 정상으로 보이는가?

### 2-3. 코드가 무슨 일을 하는지 물어보기

바이브 코딩에서도 내 코드는 내가 이해해야 한다. 한 번은 꼭 물어본다.

```text
방금 만든 코드에서 <head>, <style>, <script> 부분이
각각 어떤 역할을 하는지 초보자도 알 수 있게 설명해줘.
```

## 5. STEP 3 — 개선(2회 이상)

### 3-1. 개선 요청 예시 (한 번에 하나씩, 미리 보기로 확인)

| 분류 | 프롬프트 예시 |
| --- | --- |
| 디자인 | 제목 글씨를 더 크게 하고, 섹션 사이 여백을 넓혀 줘 |
| 기능 | 오른쪽 위에 다크모드 전환 버튼을 추가해 줘 |
| 기능 | 메뉴를 누르면 해당 섹션으로 부드럽게 스크롤되게 해 줘 |
| 효과 | 스크롤할 때 카드가 아래에서 위로 나타나는 애니메이션을 넣어 줘 |
| 반응형 | 모바일에서 프로젝트 카드가 한 줄에 하나씩 나오게 해 줘 |

### 3-2. 수정이 꼬였을 때

| 상황 | 대처 |
| --- | --- |
| 원하지 않는 방향으로 바뀜 | "방금 수정은 취소하고, 바로 전 버전으로 돌아가줘." |
| 오류가 나거나 화면이 깨짐 | "화면이 [이렇게] 보여. 원인을 설명하고 고친 전체 코드를 다시 줘." |
| 대화가 너무 길어짐 | 최종 코드를 복사해 **새 채팅에 붙여넣고** 이어서 요청(컨텍스트 원리) |

### 3-3. 최종본 저장

1. Claude 화면에서 최종 코드의 **복사** 버튼 클릭
2. 내 PC에서 메모장(또는 VS Code)을 열고 붙여넣기
3. 파일 이름 `index.html`, 인코딩 **UTF-8**로 저장
4. 저장한 파일을 더블클릭 → 브라우저에서 정상으로 보이는지 확인

> STEP 4-A(VS Code)로 진행할 경우 저장 없이 코드만 복사해 두어도 된다. B(MobaXterm)·C(scp)는 PC에 파일이 있어야 한다.

## 6. STEP 4 — 서버 접속

세 방법 중 하나를 고른다. **A가 기본**, 계속 실패하면 무리하지 말고 B(Windows) 또는 C(Mac·Linux)로 전환한다.

### 4-A. VS Code Remote SSH (기본, 모든 OS)

1. VS Code 실행 → 확장(Extensions) 아이콘(Ctrl+Shift+X / Mac ⌘+Shift+X)
2. **Remote - SSH** 검색 → Microsoft 제작 확장 설치
3. F1(또는 Ctrl+Shift+P / Mac ⌘+Shift+P) → `Remote-SSH: Connect to Host...` 선택
4. `root@<공인 IP>` 입력 후 Enter
5. 운영체제 선택 창에서 **Linux**, 처음 접속 시 지문(fingerprint) 확인 → **Continue**
6. root 비밀번호 입력
7. 왼쪽 아래 상태 표시줄에 `SSH: <공인 IP>`가 보이면 성공. 메뉴 **터미널 → 새 터미널**에서 확인:

   ```bash
   whoami            # root
   ls /var/www/html  # index.html
   ```

### 4-B. MobaXterm (Windows 대안)

1. MobaXterm 실행 → 왼쪽 위 **Session** → **SSH**
2. Remote host에 공인 IP 입력, **Specify username** 체크 → `root`
3. OK → root 비밀번호 입력
4. 터미널에 `root@...:~#` 프롬프트가 보이고 왼쪽에 SFTP 파일 탐색기가 열리면 성공 → `ls /var/www/html`

### 4-C. 터미널 ssh (macOS · Linux 대안)

1. 터미널 열기 — Mac: ⌘+Space → "터미널" / Linux: Ctrl+Alt+T
2. 접속:

   ```bash
   ssh root@<공인 IP>
   ```

3. 처음이면 `(yes/no)?` → `yes`, root 비밀번호 붙여넣기 → Enter (입력해도 화면에 안 보이는 것이 정상)
4. `ls /var/www/html`로 `index.html` 확인. 끝낼 때는 `exit`

> Mac에서도 VS Code Remote SSH(4-A)가 가장 편하다. 터미널은 VS Code가 안 될 때의 대안이다.

## 7. STEP 5 — 배포

### 5-1. 어제 파일 백업 (공통, 반드시 먼저)

```bash
cd /var/www/html
cp index.html index_day1.html
ls   # index.html 과 index_day1.html 이 모두 보이면 OK
```

### 5-2. 방법별 교체

**A. VS Code**

1. 파일 → 폴더 열기 → `/var/www/html` 입력 → 확인(비밀번호를 다시 물으면 입력)
2. 왼쪽 탐색기에서 `index.html` 클릭
3. Ctrl+A(Mac ⌘+A)로 전체 선택 → Delete
4. Claude에서 복사한 최종 코드 붙여넣기 → Ctrl+S(Mac ⌘+S)로 저장

**B. MobaXterm**

1. 왼쪽 SFTP 탐색기 위쪽 경로 칸에 `/var/www/html` 입력 → Enter
2. 내 PC에 저장한 `index.html`을 탐색기 창으로 끌어다 놓기
3. 덮어쓰기 확인 창에서 **예**

**C. Mac · Linux 터미널(scp)** — 서버가 아닌 **내 PC의 새 터미널 창**(⌘+N)에서 실행

```bash
scp ~/Downloads/index.html root@<공인 IP>:/var/www/html/index.html
```

root 비밀번호 입력 후 `index.html 100%`가 나오면 완료. **scp는 확인 없이 바로 덮어쓰므로** 5-1 백업을 먼저 했는지 확인한다.

### 5-3. 반영 확인 (공통)

```bash
head -n 10 /var/www/html/index.html   # 내가 만든 코드의 첫 부분이 보이면 배포 완료
```

## 8. STEP 6 — 확인 및 제출

1. 브라우저에서 `http://<공인 IP>` 접속. 예전 페이지가 보이면 **강력 새로고침**(Ctrl+F5 / Mac ⌘+Shift+R)
2. 스마트폰으로도 접속해 모바일 화면 확인
3. 강사 안내에 따라 제출:
   - [ ] 내 웹사이트 주소 `http://<공인 IP>`
   - [ ] 브라우저 화면 캡처 1장
   - [ ] 개선에 사용한 프롬프트 중 가장 효과적이었던 것 1개

## 9. 자주 막히는 지점

### 접속 문제

| 증상 | 확인할 것 |
| --- | --- |
| 브라우저에서 사이트가 안 열림 | ACG 인바운드 80번 허용 여부 / 웹서버 실행 여부 |
| VS Code·MobaXterm·터미널 연결 시간 초과 | ACG 인바운드 22번 허용 여부 / 공인 IP 오타 |
| 비밀번호가 계속 틀림 | Day 1에 확인한 root 비밀번호 재확인(복사 시 앞뒤 공백 주의) |
| VS Code가 연결 중에서 멈춤 | VS Code 재시작 후 재시도 → 그래도 안 되면 MobaXterm(Windows) · 터미널 ssh(Mac)로 전환 |

### 웹서버 상태 확인 (Day 1에 설치한 웹서버에 맞게)

```bash
# Nginx를 설치한 경우
systemctl status nginx
systemctl restart nginx

# Apache를 설치한 경우
systemctl status apache2
systemctl restart apache2
```

`active (running)`이 보이면 정상 동작 중이다.

### 화면 문제

| 증상 | 해결 방법 |
| --- | --- |
| 한글이 깨짐 | `<head>` 안에 `<meta charset="UTF-8">` 확인 / 파일을 UTF-8로 저장 |
| 예전 페이지가 계속 보임 | 강력 새로고침(Ctrl+F5 / ⌘+Shift+R) / 저장(Ctrl+S)했는지 확인 |
| 디자인이 깨지고 글자만 보임 | 코드 일부만 복사됨 → Claude에서 전체 코드를 다시 복사 |
| 화면이 하얗게 비어 있음 | 붙여넣기 전 내용이 남아 있는지 확인 / `index_day1.html`로 복구 후 재시도 |

### 복구 방법

```bash
cd /var/www/html
cp index_day1.html index.html
```
