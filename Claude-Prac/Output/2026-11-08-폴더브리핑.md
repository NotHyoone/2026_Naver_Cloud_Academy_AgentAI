# 폴더 브리핑: Claude-Prac와 에이전틱 AI 과정 자료

> 작성일: 2026-11-08 · 작성: Claude Code
> 요청 프롬프트: "이 폴더에 있는 모든 것을 살펴보고, 알게 된 내용에 대한 브리핑을 작성해줘 — 폴더에 무엇이 있는지, 문서들이 서로 어떻게 연관되어 있는지, 놀라운 발견이 있는지, 또는 공유할 만하다고 생각되는 다른 정보가 있는지."

**가장 중요한 발견:** 요청한 프롬프트는 Day 3 실습(Lab 02 STEP 2-2 "몸풀기 — 폴더 브리핑 받기")에 나오는 문장과 똑같다. 그런데 이 실습의 재료인 `Input/` 폴더의 파일 두 개가 모두 비어 있다(0바이트). 그래서 이 브리핑은 실습 파일이 아니라 주변의 강의자료를 바탕으로 썼다.

## 1. 폴더에 있는 것

| 위치 | 내용 |
|---|---|
| **Claude-Prac/** (실습 폴더) | `Input/강의메모.txt`, `Input/지출내역.csv`가 모두 비어 있고, `Output/`도 비어 있음 |
| **Claude Code 세션의 작업 폴더** (Git 작업 사본) | `Day1/정리.md`와 PDF 3개(OT, Day 1 이론 121쪽, Day 1 실습 76쪽) |
| **저장소에는 있지만 커밋 안 된 파일** | Day 2~4 이론·실습 PDF 6개, 「2026년 10월 최신판 AI 모델 철저 비교」 PDF |

Claude-Prac가 Git 저장소 안에 있어서, Claude Code 세션이 커밋된 내용만 담은 작업 사본에서 열렸다. 그래서 커밋하지 않은 Day 2~4 자료와 Input 파일은 세션 폴더에 보이지 않았고, 원래 폴더로 직접 가서 확인했다.

## 2. 문서들이 서로 연결되는 방식

과정 전체가 **Day 1에 만든 서버 하나를 계속 쓰는 구조**다.

- **OT**: 과정의 틀을 정한다. 10/31~11/22 주말 8일, 총 40시간이고, Claude Code·MCP·자격증까지 다룬다.
- **Day 1 (10/31)**: NCP에 VPC와 Ubuntu 서버 `yau-web-svr-01`을 만들고, Nginx로 `index.html`을 띄운 뒤 `index_day1.html`로 백업한다. `Day1/정리.md`는 이 두 PDF를 잘 요약한 노트다.
- **Day 2 (11/1)**: claude.ai 채팅으로 만든 `index.html`을 같은 서버에 배포한다.
- **Day 3 (11/7)**: Cowork에 폴더를 연결해서 맡긴다. **바로 이 Claude-Prac 실습이 여기 해당한다.** 지출 정리 결과로 `calendar.html`을 만들어 같은 서버에 올린다.
- **Day 4 (11/8)**: 같은 서버에 Claude Code를 설치하고, `CLAUDE.md`, 메모 앱, GitHub, 서버 이미지 복구를 다룬다.
- **AI 모델 비교 PDF**: Day 2·3의 "모델을 용도에 맞게 고르기"를 보완하는 따로 떨어진 참고 자료다.

## 3. 눈에 띄는 발견

**실습 관련**
- **Input 파일이 비어 있다.** Day 3 슬라이드에 `지출내역.csv` 샘플이 그대로 나온다. `날짜,항목,분류,금액` 열에 5행(학식 5,500 / 교재 18,000 / 버스 1,500 / 카페 4,800 / USB 12,000)이고, 합계는 41,800원이다. `강의메모.txt`에 들어갈 내용은 슬라이드에 없다.
- **폴더 이름이 자료마다 다르다.** 실습 덱은 `Claude-실습/입력·결과`, 이론 덱은 `Claude-lab`, 실제 폴더는 `Claude-Prac/Input·Output`이다.

**서버 반납 시점이 자료끼리 충돌한다**
- Day 1은 "Day 2가 끝나면 서버와 공인 IP를 반납"하라고 한다.
- 실제로는 Day 3·4도 같은 서버를 쓰고, Day 4 Lab 08에서 이미지로 `svr-02`를 만든 뒤 예전 서버를 반납한다.
- **Day 1 지시대로 반납하지 않은 게 맞다.** 그 대신 10/31부터 서버와 공인 IP 요금이 크레딧에서 계속 빠지고 있다.

**Day 2 예고와 실제 내용이 다르다**
- Day 1 슬라이드는 Day 2를 "Claude Code CLI 심층 탐색 & Git"으로 예고했다.
- 실제 Day 2는 채팅 방식의 바이브 코딩이었고, Claude Code는 Day 4로 미뤄졌다.

**Day 1 자료와 노트의 오류**
- **서버 사양:** 실습 덱과 `정리.md`는 "Standard 2 vCPU/4GB"라고 적었다. 하지만 이론 덱에서는 Standard가 CPU:메모리 1:4(2 vCPU면 8GB)이고, 1:2는 **High CPU**다.
- **.pem 키:** 실습 덱은 "재다운로드 불가, 비밀번호를 확인하는 유일한 수단"이라고 하는데, 이론 덱에는 "인증키 변경"으로 복구하는 방법이 있다.
  - 실습 덱은 `ssh -i` 방식에서 `Permission denied (publickey)`가 나오면 비밀번호 방식으로 접속하라며 비밀번호 방식을 권장한다.
  - 노트에는 키 파일 방식이 먼저 적혀 있다.

**Day 1 이론 덱이 오래된 자료를 재사용했다**
- 목차에는 Part 6~10(API·HMAC, K8s, RAID, 종합 프리뷰)이 있지만 본문에는 없다.
- "'21년 10월 기준", "'22.01 기준 VPC는 한국·싱가포르만", CentOS, Ubuntu 16.04 같은 몇 년 전 정보가 남아 있다.
- 서브 계정 정책 이름과 로그인 URL 형식이 이론 덱과 실습 덱에서 다르다.
- `정리.md` 맨 위에 "자료 작성 시점의 내용일 수 있다"는 주의 문구를 넣은 건 잘한 선택이다.

**OT 자료의 흔적**
- 꼬리말에 다른 과정 이름("대구대학교x영남대학교 … 클라우드 Advanced 과정")이 남아 있다.
- "7페이지(간지)", "DevOps등" 같은 템플릿 문구도 그대로다.
- "5주간"이라고 했지만 실제 일정은 주말 4번이다.

**AI 모델 비교 PDF는 그대로 믿기 어렵다**
- 표지에 "GOOGLE MATERIAL PRESENTATION · OFFICIAL EDITION"이라고 적혀 있지만 출처가 확인되지 않는다.
- 표 안에서도 앞뒤가 안 맞는다.
  - Gemini의 최대 출력 100만이 입출력을 합친 컨텍스트 한도와 같다.
  - GPT의 캐시 쓰기 비용이 일반 입력 비용보다 비싸다.
- Haiku와 HyperCLOVA X는 빠져 있다.
- Day 3 덱의 예시 화면은 "Sonnet 4.6"인데 이 자료는 Sonnet 5.5를 기준으로 한다.
- 가격과 벤치마크는 공식 자료와 대조하지 못했으니 claude.com/pricing 같은 공식 문서에서 확인한다.

## 4. 알아두면 좋은 것

**Git 저장소 정리**
- `.gitignore`가 없다. Day 4 Lab 06도 권하듯 `*.pem`이나 기록 카드 파일은 커밋되지 않게 막아 두는 게 안전하다.
- Day 1 PDF(약 44MB)만 커밋됐고 Day 2~4 PDF는 커밋되지 않아서 관리 방식이 섞여 있다.
- 원격 저장소는 GitHub(`NotHyoone/2026_Naver_Cloud_Academy_AgentAI`)다. 공개 여부는 확인하지 못했다. 공개 저장소라면 "(공유용)" 표시가 없는 강의 PDF와 운영진 실명이 나오는 OT 자료가 그대로 외부에 공개되는 셈이니 Private로 바꾸는 걸 권한다.

**노트와 남은 일정**
- 노트는 Day 1만 있고 Day 2·3 노트는 없다.
- 남은 일정
  - 본 교육: 11/14·15, 11/21·22
  - 1784 투어: 11/24(화)
  - 자격증 시험: 11월 4주차~12월 1주차
  - 수료식: 12/8(화)
- 수료 조건은 출석 80% 이상이다. 8일 중 7일은 나와야 하니 결석은 사실상 하루만 가능하고, 조퇴는 0.5일 결석으로 계산된다.
